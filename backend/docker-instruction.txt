
//before practical setup backend with prisma
FROM node:22-alpine

WORKDIR /app

COPY package*.json ./

RUN npm install

COPY . .

RUN npx prisma generate
RUN npm run build
RUN npm prune --production

EXPOSE 4000

CMD ["node", "dist/server.js"]

 , in that above COPY . . copies every file in your project (like source code). Every time you change a single line of application code, Docker invalidates the cache from that point forward. This forces npx prisma generate to rerun completely from scratch on every single build, even if your database schema never changed.
